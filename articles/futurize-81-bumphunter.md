# Parallelize 'bumphunter' functions

![The 'futurize' hexlogo](../reference/figures/futurize-logo.webp)=
![The 'future' logo](../reference/figures/future-logo.webp)

The **futurize** package allows you to easily turn sequential code into
parallel code by piping the sequential code to the
[`futurize()`](https://futurize.futureverse.org/reference/futurize.md)
function. Easy!

## TL;DR

\
[`library`](https://rdrr.io/r/base/library.html)`(`[`futurize`](https://futurize.futureverse.org)`)`\
[`plan`](https://future.futureverse.org/reference/plan.html)`(``multisession``)`\
[`library`](https://rdrr.io/r/base/library.html)`(`[`bumphunter`](https://github.com/rafalab/bumphunter)`)`\
\
`bumps`` ``<-`` `[`bumphunter`](https://rdrr.io/pkg/bumphunter/man/bumphunter.html)`(``mat``, ``design``, chr ``=`` ``chr``, pos ``=`` ``pos``, cutoff ``=`` ``0.5``, B ``=`` ``100``)`` ``|>`` `[`futurize`](https://futurize.futureverse.org/reference/futurize.md)`(``)`

## Introduction

This vignette demonstrates how to use this approach to parallelize the
**[bumphunter](https://bioconductor.org/packages/bumphunter/)**
functions.

The **[bumphunter](https://bioconductor.org/packages/bumphunter/)**
Bioconductor package provides tools for finding “bumps”, that is,
genomic regions where a covariate of interest is associated with the
measured signal, e.g. differentially methylated regions (DMRs) in DNA
methylation data. The statistical significance of the bumps is assessed
using permutations or bootstrap resampling, which can be computationally
expensive. Internally, **bumphunter** parallelizes via
[`foreach()`](https://rdrr.io/pkg/foreach/man/foreach.html) using
whatever foreach backend is registered.

### Example: Finding bumps in parallel

The [`bumphunter()`](https://rdrr.io/pkg/bumphunter/man/bumphunter.html)
function identifies candidate regions and assesses their significance by
comparing them to a null distribution generated by `B` permutations:

\
[`library`](https://rdrr.io/r/base/library.html)`(`[`bumphunter`](https://github.com/rafalab/bumphunter)`)`\
\
`# Create example data with a bump on chr1`\
`pos`` ``<-`` `[`list`](https://rdrr.io/r/base/list.html)`(`\
`  pos1 ``=`` `[`seq`](https://rdrr.io/r/base/seq.html)`(``from ``=``    ``1L``, to ``=`` ``1000L``, by ``=`` ``35L``)``,`\
`  pos2 ``=`` `[`seq`](https://rdrr.io/r/base/seq.html)`(``from ``=`` ``2001L``, to ``=`` ``3000L``, by ``=`` ``35L``)``,`\
`  pos3 ``=`` `[`seq`](https://rdrr.io/r/base/seq.html)`(``from ``=``    ``1L``, to ``=`` ``1000L``, by ``=`` ``50L``)`\
`)`\
`chr`` ``<-`` `[`rep`](https://rdrr.io/r/base/rep.html)`(`[`paste0`](https://rdrr.io/r/base/paste.html)`(``"chr"``, `[`c`](https://rdrr.io/r/base/c.html)`(``1``, ``1``, ``2``)``)``, times ``=`` `[`lengths`](https://rdrr.io/r/base/lengths.html)`(``pos``)``)`\
`pos`` ``<-`` `[`unlist`](https://rdrr.io/pkg/BiocGenerics/man/unlist.html)`(``pos``, use.names ``=`` ``FALSE``)`\
[`set.seed`](https://rdrr.io/r/base/Random.html)`(``42``)`\
`mat`` ``<-`` `[`matrix`](https://rdrr.io/r/base/matrix.html)`(`[`rnorm`](https://rdrr.io/r/stats/Normal.html)`(`[`length`](https://rdrr.io/r/base/length.html)`(``pos``)`` ``*`` ``10L``)``, nrow ``=`` `[`length`](https://rdrr.io/r/base/length.html)`(``pos``)``, ncol ``=`` ``10L``)`\
`mat``[``1``:``10``, ``6``:``10``]`` ``<-`` ``mat``[``1``:``10``, ``6``:``10``]`` ``+`` ``2`\
`design`` ``<-`` `[`cbind`](https://rdrr.io/pkg/BiocGenerics/man/cbind.html)`(``1``, `[`rep`](https://rdrr.io/r/base/rep.html)`(``0``:``1``, each ``=`` ``5L``)``)`\
\
`bumps`` ``<-`` `[`bumphunter`](https://rdrr.io/pkg/bumphunter/man/bumphunter.html)`(``mat``, ``design``, chr ``=`` ``chr``, pos ``=`` ``pos``, cutoff ``=`` ``0.5``, B ``=`` ``100``)`

Here
[`bumphunter()`](https://rdrr.io/pkg/bumphunter/man/bumphunter.html)
runs sequentially, but we can easily make it run in parallel by piping
to
[`futurize()`](https://futurize.futureverse.org/reference/futurize.md):

\
[`library`](https://rdrr.io/r/base/library.html)`(`[`futurize`](https://futurize.futureverse.org)`)`\
\
`bumps`` ``<-`` `[`bumphunter`](https://rdrr.io/pkg/bumphunter/man/bumphunter.html)`(``mat``, ``design``, chr ``=`` ``chr``, pos ``=`` ``pos``, cutoff ``=`` ``0.5``, B ``=`` ``100``)`` ``|>`` `[`futurize`](https://futurize.futureverse.org/reference/futurize.md)`(``)`

This will distribute the permutations across the available parallel
workers, given that we have set up parallel workers, e.g.

\
[`plan`](https://future.futureverse.org/reference/plan.html)`(``multisession``)`

The built-in `multisession` backend parallelizes on your local computer
and works on all operating systems. There are [other parallel
backends](https://www.futureverse.org/backends.html) to choose from,
including alternatives to parallelize locally as well as distributed
across remote machines, e.g.

\
[`plan`](https://future.futureverse.org/reference/plan.html)`(``future.mirai``::`[`mirai_multisession`](https://future.mirai.futureverse.org/reference/mirai_multisession.html)`)`

and

\
[`plan`](https://future.futureverse.org/reference/plan.html)`(``future.batchtools``::`[`batchtools_slurm`](https://future.batchtools.futureverse.org/reference/batchtools_slurm.html)`)`

### Smoothing

When using `smooth = TRUE`, the smoothing of the estimates is also
parallelized:

\
`bumps`` ``<-`` `[`bumphunter`](https://rdrr.io/pkg/bumphunter/man/bumphunter.html)`(``mat``, ``design``, chr ``=`` ``chr``, pos ``=`` ``pos``, cutoff ``=`` ``0.5``, B ``=`` ``100``,`\
`                    smooth ``=`` ``TRUE``)`` ``|>`` `[`futurize`](https://futurize.futureverse.org/reference/futurize.md)`(``)`

### Parallel random number generation

The **bumphunter** package uses
**[doRNG](https://cran.r-project.org/package=doRNG)** to generate
statistically sound random numbers in parallel. Because of this, you do
not have to specify `futurize(rng = TRUE)`. The results are reproducible
given [`set.seed()`](https://rdrr.io/r/base/Random.html), regardless of
the number of parallel workers, and they are identical to those of a
sequential run.

## Supported Functions

The following **bumphunter** functions are supported by
[`futurize()`](https://futurize.futureverse.org/reference/futurize.md):

- [`bumphunter()`](https://rdrr.io/pkg/bumphunter/man/bumphunter.html)
- [`bumphunterEngine()`](https://rdrr.io/pkg/bumphunter/man/bumphunter.html)
- [`smoother()`](https://rdrr.io/pkg/bumphunter/man/smoother.html)
